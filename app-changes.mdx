# 앱 반영 목록

시안 버전마다 **앱에 고쳐야 할 것**을 빠짐없이 적는다. 맨 위가 최신 버전이다.

- 기준은 **출시된 앱**이다(지금 iOS 1.2.1). 아직 앱에 안 들어간 버전은 아래 버전부터 차례로 반영한다.
- 같은 화면을 뒤 버전이 다시 고쳤으면 뒤 버전 값이 이긴다. 그 항목에는 「→ 1.x에서 바뀜」이라고 적어 둔다.
- 앱에 반영하면 그 버전 제목 옆 상태를 「반영됨 (iOS x.y.z)」로 바꾼다.
- 문구는 한국어가 정본이다. 시안은 한국어만 본다. 앱 문자열 키가 영어라서 **영어 값은 앱에 반영할 때 한국어 뜻에 맞춰 같이 고친다** — 따로 정해 주지 않는다.
- 항목 하나 = 시안 화면 id · 지금 앱(AS-IS) · 바꿀 값(TO-BE) · 앱 위치.

## seed_picker_opened 1.0 — 2026-10-16 · 상태: 시안 (기획 확인 대기 2건)

마이 → 「추천 기준 곡」을 날짜별 가로 줄(CrateCell)에서 **좋아요한 곡 세로 목록 + 장르 필터**로 바꾼다. 화면 명세 seed_picker_opened 1.0(2026-10-14) 기준. 1.3의 3번(마이 추천 기준 곡 비활성·트레이)을 이 버전이 덮는다.

- 명세와 다르게 그린 곳(디자인 시스템에 맞춤): 팝업 확인 버튼은 시스템 파랑 대신 `brand`, 가운데 정렬(Popup) · 트레이 빼기 표시는 ─ 대신 기존 ✕(온보딩 트레이와 같게)

   - ⓘ 탭 → 말풍선 「아무것도 고르지 않으면 최근 좋아요한 3곡을 기준으로 노래를 찾을게요.」 2초 뒤 페이드 아웃, 바깥 탭 = 바로 닫힘. 수치는 Tooltip 명세

   - 제목 아래 한 줄 가로 스크롤 칩. 「전체」 기본·맨 앞, 나머지는 **이 유저가 좋아요한 곡의 장르만, 곡 많은 순**(없는 장르는 안 보임)

5. **고른 곡 트레이** (`seed-picker*`, SeedTray `hint`)
   - 위치·크기는 1.3 그대로(탭바 위 12, 좌우 16, 안쪽 12·16). 카드 지면 `surface` → `background`(흰색) + 그림자 — 명세가 흰 카드
   - 안내 문구가 남은 칸 수를 말한다: 0곡 「최대 3곡까지 담을 수 있어요」 · 1곡 「2개 더 선택할 수 있어요」 · 2곡 「1개 더 선택할 수 있어요」 · 3곡 「곡은 3개까지 선택할 수 있어요」 또는 「3곡을 다 골랐어요」(확인 대기 — 위)
   - **커버 탭 = 빼기**(✕와 같음). 1.3의 「커버 탭 → 그 곡으로 스크롤」은 없앤다 — 세로 목록이라 찾기 쉽고, 장르 필터 중이면 그 곡이 목록에 없을 수 있다
6. **저장 버튼** (`seed-picker` 0곡, `seed-picker` 「고정 다 뺌」)
   - **들어올 때 고정과 달라졌으면 활성** — 지금 앱 규칙(`selected != savedSelection`) 그대로. 명세의 「1곡 이상이면 활성」은 따르지 않는다(2026-10-16 확정): 고정을 다 빼고 0곡으로 저장(= 최근 좋아요 3곡 기준으로 되돌리기)도 돼야 한다
   - 아무것도 안 바꿨으면 `textTertiary`(비활성)
7. **좋아요한 곡이 없을 때** (`seed-picker-empty`, Components › EmptyState 신규)
   - AS-IS: 가운데 「아직 좋아요한 트랙이 없어요」 글자만
   - TO-BE: 아이콘 원(56 `brandLight`, 「!」 `brand`) + 「아직 좋아요한 곡이 없어요」(`title2`) + 「피드에서 마음에 드는 곡을 골라주세요」(`body` `textSecondary`) + 버튼 「곡 찾으러 가기」(Button `small`) → **피드 탭으로 이동**. 저장 버튼·제목 영역·필터·트레이 없음
   - 명세의 「온보딩 곡이 따로 저장돼 있다면 그걸 보여 줄 것」: 온보딩에서 고른 곡은 이미 좋아요로 저장된다(`SeedPoolPickerView.finish()` → `hype`). 그래서 온보딩 곡이 있는 유저는 목록에 이미 나오고, 이 빈 화면은 온보딩을 건너뛰고 좋아요도 없는 유저에게만 뜬다 — 따로 할 일 없음
   - 불러오기 실패는 이 화면이 아니라 지금처럼 「불러오지 못했어요」
