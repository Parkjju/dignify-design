# Tooltip (설명 말풍선)

> 상태: 제안 (seed_picker_opened 1.0, 2026-10-16)

## 언제 쓰나
제목 옆 ⓘ(`ic-info-circle`)를 눌렀을 때 짧은 보충 설명. 지금은 마이 「추천 기준 곡」 하나 — 「아무것도 고르지 않으면 최근 좋아요한 3곡을 기준으로 노래를 찾을게요.」

## Anatomy
```
 고른 곡을 기준으로 노래를 찾을게요. ⓘ
                 ┌──────────────────────────┐
                 │ 아무것도 고르지 않으면 …     │  ← ⓘ 아래 8, 오른쪽 끝을 화면 여백(16)에 맞춤
                 └──────────────────────────┘
```

## 동작
- ⓘ 탭 → 0.18s 페이드 인, **2초 머문 뒤** 0.4s 페이드 아웃
- 말풍선 밖 아무 데나 탭 → 바로 사라짐. 떠 있는 동안 ⓘ를 다시 누르면 2초를 다시 센다
- 동작 줄이기 설정이면 페이드 없이 나타났다 사라진다
- VoiceOver: ⓘ 버튼 라벨에 같은 문장을 넣는다(말풍선은 2초라 못 읽는다)

## 수치
| 항목 | 토큰 |
|---|---|
| 지면 | `color.textPrimary` |
| 글자 | `color.textOnDark`, `typography.caption`, 줄높이 1.5 |
| 여백 | 상하 `spacing.x2_5`, 좌우 `spacing.x3_5` |
| 라운드 | `radius.small` |
| 그림자 | 0 6 16 검정 18% |

## 플랫폼
| | 이름 | 위치 |
|---|---|---|

| Android | (신규) | `feature/mypage/SeedPickerScreen.kt` — `Popup` |

## 하지 말 것
- 꼭 알아야 하는 정보를 여기에만 두지 않는다. 2초면 사라진다.
