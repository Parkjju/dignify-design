# FeedBuilding (피드 구성 중)

> 상태: 제안 (2026-10-09)

## 언제 쓰나
추천 기준 곡을 고른 직후, 첫 피드를 받는 동안. 고른 곡이 피드를 만든다는 걸 보여 주는 대기 화면이다.
앱 실행·로그인 직후처럼 아직 아무것도 고르지 않은 대기는 로고 로딩(`onboarding-loading`)을 쓴다.

## Anatomy
```
        ┌──┐┌──┐┌──┐     ← 고른 곡 커버(최대 3), 겹쳐 펼침 · 차례로 둥실
        └──┘└──┘└──┘
  취향에 맞춰 피드를 구성하고 있어요…   ← title2, 말줄임 점 차례로 깜빡
     고른 곡과 비슷한 소리를 찾는 중이에요  ← body, textSecondary
```

## 노출 시간
- **최소 1초.** 응답이 먼저 와도 1초는 보여 준다(깜빡임 방지).
- 응답이 늦으면 올 때까지 계속 보여 준다. 목표 1~2초.
- 끝나면 페이드로 피드(또는 코치마크)로 넘어간다.

## 수치
| 항목 | 값 |
|---|---|
| 커버 | 96, `radius.small`, 서로 −20 겹침, 회전 −8° / 0 / 8° |
| 커버 모션 | 위로 8 둥실, 1.6s 주기, 0.2s 간격으로 차례로 |
| 제목 | `typography.title2` |
| 본문 | `typography.body` `color.textSecondary` |
| 커버 ↔ 제목 | `spacing.x8` |

`prefers-reduced-motion`이면 커버·점 모두 멈춘다.
