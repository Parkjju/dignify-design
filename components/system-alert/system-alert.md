# SystemAlert (OS 알림 권한 팝업 자리표시)

> 상태: 시안 전용 — 앱이 그리지 않는다(iOS `requestAuthorization`이 띄운다)

## 언제 쓰나
프로토타입에서 「알림 받기」 → 기기 권한이 **설정 전**일 때 이어지는 OS 팝업을 보여 주려고 둔다. 문구·모양은 iOS 26 시스템 알럿을 흉내 낸 것이라 디자인 토큰을 쓰지 않는다.

## 동작
- 허용 → 기기 알림 권한 「켜짐」, 허용 안 함 → 「꺼짐」. 어느 쪽이든 광고성 동의는 이미 저장됐고 결과 토스트가 이어진다
- 권한을 한 번 정하면 iOS는 다시 띄워 주지 않는다 → 그 뒤엔 설정 앱 Dignify 알림 화면으로 보낸다

## 하지 말 것
- 우리 팝업(Popup)을 이 모양으로 그리지 않는다. 진짜 시스템 팝업이 바로 뒤에 오므로, 흉내 내면 가짜 시스템 대화상자가 된다
