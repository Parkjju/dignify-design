# ConsentSheet (좋아요 시점 신곡 알림 제안)

> 상태: 제안 (푸시알림 기획 ad_btmsheet_like 1.0, 2026-11-12)

## 언제 쓰나
피드에서 곡을 좋아요하고 **다음 곡으로 넘어간 직후**, 그 아티스트의 신곡 알림을 권하는 바텀시트(플로우 P05). 지금 앱의 좋아요 직후 팝업(`PushOptInPopup` 「%@ 신곡이 나오면 알려 드릴까요?」)을 대신한다. 첫 실행·야간 동의는 가운데 팝업(Popup `row`)이다.

## Anatomy
```
╭──────────── 흰 시트, 위 모서리만 둥금 ────────────╮
│                ↕ 24                              │
│          {아티스트} 신곡      ← title1, brand     │
│         소식을 받아보세요!     ← title1             │
│                ↕ 12                              │
│  소식을 받으려면 기기 설정 > 알림을 켜주세요. ← bodySmall, 「기기 설정 > 알림」 semibold │
│                ↕ 24                              │
│     ┌ 알림 미리보기 343×120 ┐ 커버 = 그 아티스트 앨범 자켓 │
│     └───────────────────────┘                     │
│  '알림 받기'를 누르면 광고성 정보 수신에 동의해요.   ← caption textTertiary (요건 추가) │
│  [          알림 받기 (50)          ]  좌우 12      │
│          일주일 동안 안 보기   ← bodySmall textSecondary │
╰──────────────────────────────────────────────────╯
  딤 color.dim(35%)
```

## 수치
| 항목 | 값 |
|---|---|
| 시트 | 화면 아래 붙음(`.sheet`), 위 안쪽 `spacing.x6`, 지면 `background` |
| 제목 | `typography.title1` 두 줄, 줄 높이 1.2. 첫 줄 「{아티스트} 신곡」 `color.brand` |
| 설명 | `typography.bodySmall`(14) `textSecondary`, 줄 높이 1.5. 제목 아래 `spacing.x3` |
| 본문 좌우 | `spacing.x4` |
| 미리보기 | 343×120, 제목 묶음 아래 `spacing.x6`. 알림 아이콘 = 좋아요한 아티스트의 앨범 자켓(어려우면 dignify 로고) |
| 하단 | 위 `spacing.x2_5`, 좌우 `spacing.x3`. 버튼 높이 50 `brand` `radius.medium` |
| 「일주일 동안 안 보기」 | 높이 34, 버튼 아래 `spacing.x3`, `bodySmall` `textSecondary` |

## 동작
- 「알림 받기」 → 광고성 동의 저장 + 시스템 권한 요청(설정 전이면) → 결과 토스트(Toast 「수신동의」)
- 「일주일 동안 안 보기」 → 닫기만. 7일 뒤 같은 조건(좋아요 → 다음 곡)에서 다시 뜬다
- 바깥(딤) 탭 → 닫기만(「일주일 동안 안 보기」와 같게 셀지는 앱에서 정한다 — 기획 미정)

## 확인 대기
- Figma에는 광고성 정보 수신 동의 문구가 없다. 동의를 받는 화면이라 `legal` 한 줄을 넣었다(2026-11-16 결정, 기획 확인 필요)
- 버튼 색: 설계서는 `brand`, 화면 원본은 검정. 설계서를 따랐다
