# CoachGesture (제스처 코치마크)

> 상태: 제안 (feed_coachmark 1.0, 2026-10-08)

## 언제 쓰나
피드 첫 진입 온보딩. **읽고 넘기는 카드(`CoachMark`)가 아니라, 손 모션을 보고 실제로 따라 해야 다음 단계로 넘어간다.**
"다음" 버튼·점(PageDots)이 없다. 피드 외 화면(Picks·마이)의 안내는 기존 `CoachMark`를 그대로 쓴다.

## Anatomy
```
        ┌───────── 아트워크 ─────────┐
        │           ☝︎  ← 손 모션     │   double-tap · swipe-up
        │                            │   (hyped 단계는 손 대신 하입 아이콘 팝)
   ┌────┴────────────────────────────┴────┐
   │       마음에 드는 노래를 찾았어요!      │  ← 제목 headline white
   │        빠르게 두 번 탭해볼까요?       │  ← 본문 callout white 70%
   └──────────────────────────────────────┘  ← pickElevated, radius.medium
```
화면을 어둡게 덮지 않는다(스포트라이트 없음) — 아트워크 자체가 대상이라서.

## Variants
| gesture | 그림 | 끝나는 조건 | 문구 |
|---|---|---|---|
| `double-tap` | 손이 1초 안에 두 번 누름 → 2초 쉼 → 반복 | 유저가 더블탭(= 실제 하입) | 마음에 드는 노래를 찾았어요! / 빠르게 두 번 탭해볼까요? |
| `hyped` | 화면 가운데 하입 아이콘 팝 → 1초 머묾 → 페이드아웃(1회). 캡션은 남는다 | 화면 아무 곳 터치 | 마음에 드는 노래를 하입했어요! / 관심이 가는 노래를 더 찾으러 가볼까요? |
| `swipe-up` | 손이 아래→위로 쓸어 올림 → 쉼 → 반복 | 유저가 다음 곡으로 스와이프 | 다음 노래로 넘어가 볼까요? / 화면을 위로 쓸어 올려보세요 |

## 수치
| 항목 | 값 |
|---|---|
| 위치 | **아트워크에 붙는다.** 손 중심 = 아트워크 가운데 −18, 캡션 = 아트워크 폭, 아래 끝이 아트워크 밑으로 25 |
| 캡션 폭 | 아트워크 폭(화면 − 48) |
| 캡션 안쪽 | 세로 `spacing.x4` · 가로 `spacing.x5` |
| 캡션 라운드 | `radius.medium` |
| 캡션 배경 | `color.pickElevated` |
| 손 | 72, 흰색 + 그림자 (애셋 미정 — 지금은 `ic-hand-tap` 근사) |
| 하입 아이콘 | 160 `color.brand` |
| 더블탭 주기 | 3초 = 탭 2회(0.0s · 0.35s) + 쉼 |
| 스와이프 주기 | 2.4초 = 쓸어 올림 1.2s + 쉼 |
| 하입 아이콘 | 팝 0.45s(오버슈트) → 머묾 1s → 페이드아웃 0.4s (시안은 2.4초 반복) |

## 모션
- `speed`로 모든 모션 빠르기를 함께 조절한다(1 = 기본, 2 = 두 배 빠르게).
- 단계가 끝나면 캡션·손(또는 아이콘)이 함께 0.2초 페이드아웃.
- 누름은 `scale(.86)` + 터치 지점 물결(ring). ease-out, 탭 하나 ≈ 150ms.
- `prefers-reduced-motion`이면 손은 멈춘 채 보이고 물결·이동이 없다.

## 하지 말 것
- "다음" 버튼을 붙이지 않는다. 동작으로만 넘어간다.
- 캡션을 아트워크 위쪽에 두지 않는다. 손이 가리키는 곳 아래, 하단 정보(제목·하입 버튼) 위에 둔다.
