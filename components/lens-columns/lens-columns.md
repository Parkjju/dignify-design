# LensColumns

> 상태: 구현됨(iOS·Android)

디깅 프로필 "주요 장르 / 주요 아티스트". 왼쪽 **탐색**(들은 것, `headphones`, 지면 `surface`, 캡션 `textSecondary`) · 오른쪽 **담음**(하입한 것, HypeIcon, 지면 `brandLight`, 캡션 `brand`). 상위 5개, 없으면 "—".

수치: 열 안쪽 12, radius 14, 행 간격 10, 이름 `bodyMedium`, 숫자 `caption` `textSecondary`. 제목 `title2`, 좌우 20.
