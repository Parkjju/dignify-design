# Picks 다크 지면

앱은 라이트 고정이다. **Picks 탭만 다크다.**

## 왜
흰 배경 위의 `surface`(#F3F4F6) 카드는 대비가 거의 없어서 아트워크가 떠 보이기만 하고 지면이 밋밋했다. 어둡게 깔면 커버가 유일한 색이 되고, 카드를 탭해 검은 재생 화면으로 넘어갈 때도 톤이 끊기지 않는다.

## 레이어
| 층 | 토큰 |
|---|---|
| 지면 | `color.pickBackground` |
| 카드 | `color.pickSurface` |
| 카드 위 시트·메뉴 | `color.pickElevated` (카드와 같은 색이면 시트가 지면에 붙어 보인다) |
| 강조(선택·하입·링크) | `color.pickAccent` (`brand`는 다크 위에서 묻힌다) |
| 텍스트 | white / white 60% |

## 하지 말 것
- Picks 밖에 다크 지면을 새로 만들지 않는다. 필요하면 이 문서부터 고친다.
- 다크 지면 위에 `color.brand`를 그대로 쓰지 않는다.
